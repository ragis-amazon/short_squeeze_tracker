# Getting Started with AI Project Hub

## Welcome!
This is your personal AI project documentation and prototyping workspace.

## How to Use

### Adding Documentation
1. Create a new `.md` file in the `docs/` directory
2. Write your PRD, notes, or documentation in Markdown
3. The app will automatically detect and display it

### Adding Code Prototypes
1. Create a new directory in `prototypes/`
2. Add your code files (`.js`, `.ts`, `.py`, etc.)
3. Name the main file `index.js`, `index.ts`, `main.js`, or `main.ts`
4. The app will automatically detect and display it

## Tips
- Use clear, descriptive names for your projects
- Keep documentation up to date
- Version your prototypes with meaningful commit messages
